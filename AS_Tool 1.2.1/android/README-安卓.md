# AnySearch 工具 · 安卓版（Kotlin + Jetpack Compose）

把桌面版「AnySearch 工具包」（`anysearch_asset_search.py` / `anysearch_downloader.py` / `anysearch_gui.py`）完整移植为安卓原生应用。

| 项目 | 值 |
| --- | --- |
| 语言 / UI | Kotlin 2.2.10 + Jetpack Compose（material3 1.3.2） |
| 构建 | Android Studio 2026.1（Quail）+ AGP 8.13.0 + Gradle 8.14.3 |
| 网络 | OkHttp 4.12.0（无其他第三方库） |
| minSdk / targetSdk | 26（Android 8.0）/ 36 |
| 包名 | `com.anysearch.android` |

---

## 直接安装现成 APK（免构建）

仓库 `apk/` 目录（或 GitHub Releases）提供已打包好的安装包：

| 文件 | 说明 |
| --- | --- |
| `apk/AnySearch-v1.2.1.apk` | 与源码同版本的现成安装包（约 17MB） |

安装步骤：

1. 把 APK 传到手机，点击安装；首次需允许“安装未知来源应用”。
2. 打开应用 → 设置页输入 API Key（可选，不填则匿名调用、限流更严）→ 开始使用。

**注意：**

- 该 APK 为 **debug 签名**（本仓库无发布证书，构建机自动生成的调试密钥），仅供快速体验；介意签名或需要长期升级的用户请按下方「构建步骤」从源码自行构建，或后续等待维护者发布正式签名版本。
- **升级提示“签名不一致”**：安卓只允许同签名覆盖升级。若你之前装过其他来源（不同签名）的旧版本，需要先卸载再安装。卸载会清空：App 内保存的 API Key、全部设置、下载任务列表与未完成下载的断点（续传失效）；保存在手机公共「下载（Download）」目录里的已下载文件不受影响。

## 一、功能对照

| 桌面版 | 安卓版 |
| --- | --- |
| 搜索（1~10 条，保存 JSON） | ✅ 搜索页：关键词 + 条数下拉 + 保存结果 + 清空 |
| 网页抓取（Markdown） | ✅ 网页抓取页：开始抓取 + 保存 Markdown |
| 提取链接 | ✅ 网页抓取页：提取链接按钮 |
| 单文件多线程下载（1~16 线程、进度/速度/剩余时间、取消） | ✅ 文件下载页：进度条 + 速度/剩余时间 + 取消 |
| 批量并行下载（独立窗口、每任务取消、连接数限制） | ✅ 批量下载界面：任务列表 + 单个取消 + 停止全部 + 连接数上限检查弹窗 |
| 假直链（返回 HTML）自动拦截 | ✅（探测首字节 + Content-Type 双重检测） |
| 网页/短链/跳转页自动解析（v1.2.1） | ✅ 下载页：直链优先；返回网页或被拒绝（403/429）时自动解析出真实直链 |
| 下载选项列表：多清晰度/多文件选择（v1.2.1） | ✅ 弹窗选择：下载选中 / 全部下载 / 取消（可设置自动选最佳） |
| 人机验证（v1.2.1） | ✅ 验证码弹窗，输入后自动提交继续 |
| Range 探测，不支持自动回退单线程 | ✅ |
| 下载完成大小校验，坏文件不保留 | ✅ |
| HTTP/HTTPS 代理 | ✅ 设置页（OkHttp Proxy，仅 HTTP/HTTPS，不支持 SOCKS，与桌面版一致） |
| 自定义请求头（API 与下载共用） | ✅ 设置页（每行 `名称: 值`） |
| 连接数上限 + 允许突破（带警告确认） | ✅ 设置页 + 批量下载弹窗 |
| API Key：文件读取 / 界面修改保存 | ✅ 顶部 Key 栏 + 保存到应用私有目录 |
| 设置保存到 `anysearch_settings.json` | ✅ 应用私有目录同名文件 |

**功能上的增强/差异：**

1. 桌面版 `anysearch_asset_search.py` 中 `extract_links` 函数只有调用、**没有定义**（桌面 GUI 点“提取链接”实际会抛异常）。安卓版按 README 描述的语义完整实现（正则提取 `http(s)://` 链接、去重保序、剥离尾部标点）。
2. 桌面版的“分块渲染大小（chunk_size）”是 tkinter 文本框卡顿的补丁，Compose 原生按需渲染不需要它，故未保留。
3. 批量下载中任一分块彻底失败会立即终止其余分块并报错（桌面版会等其余分块下完才报错），结果相同、更快止损。
4. 文件名会剔除 `\ / : * ? " < > |` 及控制字符（安卓存储要求；桌面版无此限制）。
5. 下载运行在前台服务 + 常驻通知中（v1.2.0 起），切后台不中断；下载全部结束后服务自动停止并清除通知。

## 二、构建步骤

### 1. 安装 Android Studio

运行你已下载的 `android-studio-quail3-windows.exe`（Google 官方签名，1.44GB），一路默认即可。首次打开会引导下载 Android SDK（需网络，请预留数 GB 空间）。

### 2. 打开本项目

启动 Android Studio → **Open** → 选择本目录（`AnySearchAndroid`）。

Gradle wrapper 已完整内置（`gradlew`、`gradlew.bat`、`gradle/wrapper/gradle-wrapper.jar` 与 `gradle-wrapper.properties`），无需任何额外准备。

### 3. 同步与构建

1. 等 Android Studio 完成 Gradle 同步（首次会下载 Gradle 8.14.3 和依赖，需要网络）。
2. 菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。
3. 产物在 `app/build/outputs/apk/debug/app-debug.apk`（约 10MB 内）。

### 4. 安装到手机

- 手机开 USB 调试连电脑：点工具栏 ▶ Run 选择设备；
- 或把 APK 传到手机直接安装（首次需允许“安装未知来源应用”）。

### 国内网络加速（可选）

- Gradle 发行包慢：把 `gradle/wrapper/gradle-wrapper.properties` 里的 `distributionUrl` 换成腾讯镜像（文件里有注释）。
- 依赖仓库慢：把 `settings.gradle.kts` 里注释掉的阿里云镜像两行取消注释。

## 三、使用说明（与桌面版一致的要点）

- **API Key**：顶部输入后点“保存 Key”，存于应用私有目录 `anysearch_api_key.txt`；留空则匿名调用（限流更严）。
- **下载**：输入框支持真实文件直链，也支持**网页 / 短链 / 跳转页**——直链直接下载不经过解析；返回网页（假直链）或被站点拒绝（403/429）时自动解析页面，提取直链并弹出选项列表（多清晰度图片 / zip、7z、apk 等多文件）；页面需要人机验证时弹出验证码输入框，输入后自动提交继续。
- **链接解析设置**：设置页可关闭“自动解析”（网页链接直接报错），或开启“自动选最佳”（多选项不弹窗）。
- **被拦截提示**：站点风控拒绝（403/429）或 Cloudflare 挑战页无法通过时，会明确提示改用浏览器手动获取真实直链；下载解析出的直链时自动携带页面 Referer（抗防盗链）。
- **断点续传**：暂停后“继续下载”复用上次解析出的直链（签名直链每次解析都不同，重新解析会丢断点）；≤1MB 但支持 Range 的小文件同样支持断点续传。
- **下载位置**（安卓特有，桌面版是任意本地目录）：
  - 系统公共下载目录（Download/）：API 29+ 走 MediaStore 无需权限；API 26~28 首次使用会申请存储权限；
  - 应用专属目录：无需任何权限，位于 `Android/data/com.anysearch.android/files/Download/downloads`；
  - 自定义文件夹：通过系统文件选择器授权（SAF），授权持久保存。
- **代理**：设置页启用并填写 `http://127.0.0.1:7890`（仅 HTTP/HTTPS 代理）。
- **自定义请求头**：每行 `名称: 值`，同时作用于 API 与下载请求；保存后明文存于设置文件，勿外传。
- **批量下载**：文件下载页 → “打开批量下载窗口”。总连接数 = 并行任务数 × 每任务线程数，超上限会被拦截（除非在设置里勾选“允许突破连接数上限”，并二次确认）。
- **保存结果**：搜索/抓取页的“保存”走系统“另存为”对话框（桌面版是本地文件对话框）。

## 四、数据与隐私

- 搜索/抓取请求发送至 `api.anysearch.com`；下载请求直连目标 URL，不消耗搜索 API 配额。
- 设置与 Key 只存于应用私有目录（`/data/data/com.anysearch.android/files/`），不上传、不读取无关系统信息。
- 应用声明了网络权限与（仅 Android 9 及以下的）写公共下载目录权限，无其他权限。

## 六、更新记录

### v1.1.0（versionCode 2）

- 修复：`AnySearchApp.kt` 缺失 `AppState` import 导致编译失败；
- 修复：material3 1.3.x 下拉菜单类实验性 API 未显式 OptIn 导致编译失败；
- 修复：委托属性智能转换（下载进度条）与设置页 `IntDropdown` 尾随 lambda 误绑定参数导致的编译失败；
- 修复：链接提取与 Content-Disposition 文件名解析同步桌面修复版——RFC 5987 `filename*` 百分号解码、中文标点剥离、纯正则实现（不依赖 cgi/email）；
- 优化：窄屏/横屏适配——设置页标签与下拉框上下排列，批量下载控制行与按钮行自动换行（FlowRow），任务列表列宽收窄；
- 清理：全部 IDE 警告（组合内 StateFlow.value 读取改用 collectAsState、Int 状态改用 mutableIntStateOf、未使用 import 等）。

### v1.2.0（versionCode 3）

- **下载引擎与桌面版同步**：自动分块（按文件大小动态计算 1~16MB）/ 手动分块（1~64MB，下载页复选框 + 设置页调节）；分块内断点重试（失败从已写字节续传）；失败 3 次暂停 → 手动重试/再次下载自动续传；跨会话断点续传（`.part`/`.meta`，ETag/Last-Modified 校验）；设置页断点缓存占用标注 + 一键清理；下载页“放弃断点”；
- **镜像源系统**：模板（`{url}` 占位）、三种策略（仅直连 / 镜像优先测速选最快 / 直连优先低速自动切换）、测速并发可设（默认 3）、内容不一致自动跳过；
- **UI 重构**：底部 4 Tab 导航；API Key 移入设置页；大圆角搜索框 + 紧凑条数胶囊；结果卡片列表（标题 + 链接 + 一键复制 + 复制全部 + 原文切换）；
- **前台服务 + 通知**：下载/批量下载切后台不中断，通知实时显示进度；
- **修复**：粘贴长链接后按钮首次点击无响应、超长链接光标无法移动（焦点管理 + 输入法动作键）。

### v1.2.1（versionCode 4）

- **链接解析（与桌面版 1.2.1 同步）**：直链优先、零额外流量——直链直接下载不经过解析，只有返回网页（假直链）或被站点拒绝（403/429）时才自动解析；
- **跳转链跟随**：HTTP 302 / `<meta>` 刷新 / JS 跳转（含 `var x = 条件 ? "A" : "B"` 三元求值）；
- **下载选项列表**：从 JSON-LD / og:image / srcset / 下载按钮 / 内联 JS 变量 / 参数嵌套直链中提取候选并按可信度排序；多候选弹窗选择（下载选中 / 全部下载 / 取消），设置可改“自动选最佳”；
- **多清晰度枚举**：尺寸 token（`_340`~`_4096`、`w=`、`@2x`、无后缀原图）自动枚举 + HEAD 验证，只列真实存在的档位；
- **人机验证**：识别验证码表单并拉取图片，输入后带会话 Cookie 提交、可多次重试；
- **断点续传增强**：暂停后“继续下载”复用上次解析出的直链（签名直链每次解析都不同，重新解析会丢断点；失效自动重新解析）；≤1MB 但支持 Range 的小文件（如 .torrent）同样支持断点续传；
- **防盗链与拦截提示**：下载解析出的直链自动携带页面 Referer；直连被拒（403/429）自动回退解析器（完整浏览器头）；Cloudflare 挑战页与风控拒绝给出明确指引（手动获取直链 / 停止使用工具）；
- **修复**：206 响应 Content-Range 无总大小时不再误用分片长度；网页识别改用 HtmlPageError 精确触发解析；镜像测速支持取消中断与 Referer；设置页新增“链接解析”开关（自动解析 / 自动选最佳）；修复“暂停后点取消”无活动任务导致界面停在“取消中”无法恢复（暂停态取消立即删除断点并恢复界面，单任务与批量行均适用）。
