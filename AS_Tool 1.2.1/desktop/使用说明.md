## 一、软件简介

一个基于 Python 标准库的通用网络小工具，包含三个模块：

| 文件 | 作用 |
| --- | --- |
| `anysearch_gui.py` | 图形界面版（推荐日常使用） |
| `anysearch_asset_search.py` | 命令行版 |
| `anysearch_downloader.py` | 多线程下载核心模块（被前两个调用） |
| `anysearch_link_resolver.py` | 链接解析模块（跳转链/页面选项/多清晰度枚举/验证码，被前两个调用） |
| `anysearch_api_key.txt` | API Key 模板文件（把里面的文字替换成你的 Key） |

功能：

- 关键词搜索
- 网页正文抓取（Markdown）
- 从网页提取链接列表
- 链接自动解析（直链优先）：直链直接下载；返回网页时才解析出真实直链与下载选项（多清晰度图片、zip/7z/apk 等多文件）
- 人机验证下载页：拉取验证码图片，输入后自动提交继续
- 单文件多线程下载（1~16 线程、自动/手动分块、断点续传、进度/速度/剩余时间、暂停/取消）
- 批量并行下载（独立窗口、每任务单独暂停/取消/重试、总连接数限制）
- 镜像源加速（`{url}` 模板、镜像优先/直连优先/仅直连三种策略、自动测速切换）
- 一键复制链接（搜索页与抓取页底部链接列表）
- HTTP/HTTPS 代理支持
- 自定义请求头
- 假直链（返回 HTML）自动拦截

## 三、使用方法

### 图形界面（推荐）

1. 把 `anysearch_api_key.txt` 里的文字替换成你的 AnySearch API Key
2. 双击或运行：
   ```
   python anysearch_gui.py
   ```
3. 窗口顶部可修改/保存 Key；底部状态栏显示运行状态

### 命令行

```
# 搜索
python anysearch_asset_search.py "关键词" -m 5

# 抓取网页正文
python anysearch_asset_search.py --extract "https://example.com/page"

# 提取网页中的链接
python anysearch_asset_search.py --extract-links "https://example.com/page"

# 下载直链文件（默认 4 线程，保存到 downloads）
python anysearch_asset_search.py --download "https://example.com/file.zip"

# 解析链接：跟随跳转并列出页面里的下载选项（不下载）
python anysearch_asset_search.py --resolve "https://pixabay.com/zh/photos/hut-cabin-tree-hills-mountains-6508006/"

# 网页/短链下载：直链失败返回网页时自动解析；多选项用 --pick 选择（best/N/URL）
python anysearch_asset_search.py --download "https://adl.netease.com/d/g/sky/c/gw" --pick best

# 下载并指定手动分块 8MB（默认自动分块）
python anysearch_asset_search.py --download "https://example.com/file.zip" --chunk-size 8

# 使用镜像源（镜像优先：立即开始下载，后台测速后自动切换最快镜像）
python anysearch_asset_search.py --download "https://github.com/user/repo/releases/download/v1/file.zip" --mirror "https://ghfast.top/{url}" --mirror-strategy mirror_first

# 放弃某链接的下载断点（配合 --out-dir 使用）
python anysearch_asset_search.py --discard "https://example.com/file.zip"
```

## 四、下载功能说明

- **只支持真实文件直链**（浏览器直接访问即可下载、无需登录的链接）。
- **不支持**：百度网盘、夸克网盘、阿里云盘等需要登录/验证码/客户端的链接；网盘分享页（返回 HTML 网页）会被自动识别并报错。
- 服务器支持 Range 分块时自动多线程；不支持或文件过小（≤1MB）时自动回退单线程（≤1MB 但支持 Range 时同样支持断点续传）。
- **分块**：默认自动分块（块大小 = 文件大小 ÷（线程数 × 4），限制在 1~16MB）；也可在设置页关闭“默认自动分块”，改用固定手动分块大小（1~64MB）。
- **断点续传**：正常下载、暂停、异常中断都会保存断点（`.part`/`.meta`，含文件大小与校验信息），下次下载同一链接自动从断点继续；点“取消”会删除未完成文件并放弃断点。设置页可查看断点缓存占用大小并一键清理。
- 单个分块失败会自动重试（从已下载字节继续）；过慢的分块会自动拆分并交给空闲线程。
- 下载完成后会校验文件大小，不完整/损坏的文件不会保留。
- 视频进度条问题：部分源文件本身不带进度索引（moov 在文件尾），可用 ffmpeg 修复：
  ```
  ffmpeg -i 输入.mp4 -c copy -movflags +faststart 输出.mp4
  ```

## 五、链接解析与验证码

下载页输入框不限于文件直链，也接受**网页 / 短链 / 跳转页**。**直链直接下载、不经过解析（零额外流量）**；只有下载目标返回**网页（假直链）**时才自动解析：

- **跳转链**：自动跟随 HTTP 302、`<meta>` 刷新、JS 跳转（含 `var xxx_link = 条件 ? "地址A" : "地址B"` 这类按条件取值的内联脚本），拿到最终地址。
- **页面内选项**：从 JSON-LD / og:image / srcset / 视频音频标签 / 下载按钮 / 内联 JS 变量中提取候选直链，例如：
  - Pixabay 图片页 → 列出 340~1280 公开清晰度 + 页面内嵌的 1920 高清签发直链（原图需浏览器点下载签发，会注明）；
  - Pexels 图片页 → 按 `w=320…4096` 参数枚举清晰度 + 原图直链；
  - GitHub Release / 软件下载页 → 列出页面里的 zip、7z、apk、exe 等全部文件。
- **选项窗口**：多个候选时弹出列表（双击或“下载选中”下载、“全部下载”逐个下载、“复制选中链接”复制、取消）。设置里可改为“自动选择最佳”。
- **验证码**：页面需要人机验证时弹出验证码图片（PNG/GIF 直接显示，JPEG 用系统图片查看器打开），输入后自动带会话 Cookie 提交，成功后继续解析/下载。
- **枚举验证**：图片清晰度候选会逐个 HEAD 验证，不存在的档位不会列出。
- **参数嵌套直链**：自动解码提取 `?url=`、`?image-url=`、`?target=`、`?redirect=` 等参数里嵌套的真实下载地址（URL 编码、协议相对地址均可）；页面路径含 `-<数字id>` 时按上下文优选主内容直链。这是通用机制，不限于特定站点。
- **被拒回退与防盗链**：直连下载被站点拒绝（403/429）时，自动改用解析器（完整浏览器头）解析页面获取真实直链；下载解析出的直链时自动携带页面 Referer（对抗防盗链）；解析出的直链绑定浏览器会话或已失效被拒时，明确提示改为浏览器复制下载链接。
- **站点扩展**：个别网站改版/新增接口时，只需在 `anysearch_link_resolver.py` 的 `SITE_RULES` 里注册一条规则（主机名正则 + 解析函数），GUI / CLI / 下载引擎无需改动（完整示例见下文）。
- **限制**：Cloudflare 等需要执行 JS 的挑战页无法自动通过（会明确提示，并建议停止使用工具下载该站点、改在浏览器中获取直链）；需要登录才能下载的原图无法获取；解析出的签名直链会过期，下载失败重试时会自动重新解析。镜像源设置对解析出的最终直链照常生效。
- **自动重试**：解析对瞬时网络错误（连接失败/5xx）自动重试 1 次；被风控拒绝（403/429 等）不自动重试、立即给出"手动获取直链"的指引；直连下载被拒（403/429）时自动改用解析器解析页面；其余解析失败需用户手动重试。分块下载失败自动重试 3 次后暂停，需手动点"继续"。

### 自定义站点规则（SITE_RULES）

某个网站改版、换了新接口，或者通用规则拿不到它的直链时，只需在 `anysearch_link_resolver.py` 顶部找到 `SITE_RULES = []`，追加一条规则即可，**GUI / CLI / 下载引擎完全不用动**。

每条规则 = `(主机名正则, 解析函数)`。解析函数收到两样东西：`html_text`（解码后的页面 HTML 文本）和 `base_url`（页面地址），返回候选列表（没命中就返回 `[]` 或 `None`）：

```python
def example_site_rule(html_text, base_url):
    """示例：某站新版页面把直链放在 JS 变量里（通用规则没抓到）。"""
    import re
    m = re.search(r'var downloadUrl = "(https?://[^"]+)"', html_text)
    if m:
        return [{"url": m.group(1),
                 "label": "新版接口直链",
                 "kind": "file",          # image / video / audio / file
                 "width": None,           # 图片可选：像素宽
                 "height": None,          # 图片可选：像素高
                 "note": "示例站点规则"}]
    return []

SITE_RULES.append((r"^example\.com$", example_site_rule))
```

候选字段说明：`url`（必填，支持相对路径，自动按页面地址拼接）；`label`（选项列表里显示的标题）；`kind`（`image`/`video`/`audio`/`file`，默认 `file`）；`width`/`height`（图片像素，用于清晰度标注与排序）；`note`（附加说明，如“原图需登录”）。

要点：
- 主机名正则匹配当前页面域名（不含端口），多条规则按注册顺序执行，命中的都会生效；
- 规则返回的候选与通用解析结果合并、按 URL 去重；规则抛异常会被忽略，不影响通用解析；
- 改完重启程序即生效；规则多了可以改成 `from my_site_rules import SITE_RULES` 单独维护，接口不变。

## 六、镜像源

- 在设置页“镜像源”区添加镜像模板，**每行一个**，用 `{url}` 代表原始下载链接，例如 `https://ghfast.top/{url}`（GitHub 加速等第三方服务请自行甄别）。
- 三种策略：
  - **仅直连（不使用镜像）**：直接访问原始链接，不使用任何镜像（默认）。
  - **镜像优先**：点下载后立即从直连开始下载，同时后台测速全部镜像，测速完成后自动切换到最快的镜像（自动切源时界面会提示）。
  - **直连优先**：从直连开始，持续低于“低速切换阈值”时按列表顺序自动切换镜像（建议把更快的镜像排在前面）。
- 镜像测速并发数可设（1~8，默认 3）；直连失败也会自动尝试镜像源。
- 镜像同样支持断点续传；内容与直连不一致或不可用的镜像会被自动跳过。

## 七、批量下载与连接数限制

- 批量下载在独立窗口：可同时下载多个链接，每行有进度、速率和单独的暂停/继续、取消、重试按钮。
- “暂停全部”后“继续全部”，恢复的任务先显示“排队中”，拿到下载名额后才开始，严格不超过并行上限。
- 总连接数 = 并行任务数 × 每任务线程数，默认上限 16。
- 设置中可开启“允许突破连接数上限”，但会弹出警告——**连接数过高可能导致 IP 被封、服务器拒绝服务或文件损坏**。
- 推荐组合：
  - 单个大文件：1 任务 × 16 线程
  - 多个文件：2 任务 × 8 线程
  - 带宽小 / 服务器易封：2 任务 × 4 线程

## 八、代理与自定义请求头

- 设置页支持 HTTP/HTTPS 代理（例如 `http://127.0.0.1:7890`）。
- 支持自定义请求头（每行一个 `名称: 值`），会同时用于 API 与下载请求。
- **注意**：自定义请求头（可能含 Cookie）会明文保存到 `anysearch_settings.json`，请勿外传该文件。

## 九、常见问题

| 问题 | 处理 |
| --- | --- |
| 提示没有 Key | 编辑 `anysearch_api_key.txt` 或在窗口顶部填写 Key |
| 下载的是网页而不是文件 | 现在会自动解析页面里的直链并列出选项；若在设置里关闭了自动解析（或 CLI 用了 `--no-resolve`），请改用真实直链（CDN） |
| 下载速度慢 | 提高线程数；若服务器按 IP 限速，多线程无效；GitHub 等源可开启镜像（见“六、镜像源”） |
| 抓取网页报 `extract_upstream_error` | 目标站反爬或 JS 渲染，AnySearch 无法抓取，换普通公开网页 |
| 进度超过 100% / 文件损坏 | 已内置校验并删除损坏文件；若频繁出现，改用单线程下载 |
| 取消下载后文件不见了 | 取消=放弃断点并删除未完成文件；只想临时停下请点“暂停”，下次自动续传 |
| 如何从上次中断处继续 | 直接再次下载同一链接即可自动续传；若点过“取消”，断点已删除，需重新下载 |
| 镜像源没生效 | 确认策略已选“镜像优先/直连优先”，且模板含 `{url}`；不可用镜像会自动跳过并回退直连 |
| 粘贴网页链接没反应/报“未找到” | 页面里确实没有直链（纯 JS 渲染、需登录、Cloudflare 挑战），会明确提示；换真实直链 |
| 提示“访问被拒绝(HTTP 403/429)” | 站点风控拒绝了自动抓取：请用浏览器打开页面、手动复制真实直链粘贴重试；持续被拒请停止使用本工具下载该站点 |
| 提示 Cloudflare 人机验证无法通过 | 该站点风控较严格、需执行 JS 才能通过：稍后重试；若持续如此，请停止使用本工具下载该站点，改在浏览器中完成验证后获取真实直链 |
| 下载/解析失败会自动重试吗 | 分块下载失败自动重试 3 次后暂停，需手动“继续”；链接解析对瞬时网络错误自动重试 1 次；被风控拒绝（4xx）不重试、直接提示；直连下载被拒（403/429）时自动改用解析器解析页面；其余失败需手动重试 |
| 弹出“人机验证”窗口 | 该站点下载前要求验证：按图输入后自动提交继续；不想验证点“取消”放弃下载 |
| 想要某个清晰度的图片 | 网页链接会自动列出全部免登录清晰度（见“五、链接解析与验证码”）；Pixabay 的 1920 高清签发直链也会列出，原图需在浏览器点下载并复制链接 |
| 设置改乱了 | 删除 `anysearch_settings.json`，重启后恢复默认 |

## 十、隐私与数据

- 搜索/抓取请求发送至 `api.anysearch.com`；下载请求直连目标 URL（或你配置的镜像源）。
- 本工具不会上传你的本地文件，不会读取与功能无关的系统信息。
- 生成的 `anysearch_settings.json` 包含你的配置（可能含代理地址、自定义请求头、镜像模板），注意保管。

## 十一、更新日志

### v1.1 · 修复版

1. **修复“提取链接”功能不可用**：`anysearch_asset_search.py` 中 `extract_links` 函数此前只有调用、没有定义，图形界面点击“提取链接”会直接报错。现已完整实现：从抓取结果（Markdown/文本）中提取全部 http/https 链接，自动去重、保持顺序，并剥离结尾标点（含中文标点）。注意：只能提取静态文本里的链接，JS 动态渲染的链接无法获取。
2. **修复命令行 `--extract-links`（`-l`）未实现**：该参数此前在说明文档中列出但实际不可用，现在可正常使用：
   ```
   python anysearch_asset_search.py --extract-links "https://example.com/page"
   ```
3. **修复 Python 3.13+ 兼容性，并扩展设备兼容范围**：下载器解析 Content-Disposition 文件名的函数原本使用 Python 3.13 起已移除的 `cgi` 模块（在 Python 3.13 / 3.14 下会报错）。现改为**纯正则手工解析**（RFC 6266 / 5987：优先 `filename*=UTF-8''…` 并做百分号解码，其次 `filename="…"`、裸值），不依赖 `cgi` / `email` 等任何可能被移除或裁剪的模块：兼容 Python 3.8 ~ 3.14、Windows / macOS / Linux，以及手机上的精简 Python 环境（Pydroid 3 / Termux 等）。解析失败自动回退 URL 文件名，绝不报错。
4. 以上修复已同步到随附的安卓版（AnySearchAndroid）对应实现，两端行为保持一致。

### v1.2.0 · 下载引擎与镜像源

**下载引擎**

1. **可变分块下载**：下载页新增“自动分块”开关——勾选时块大小 = 文件大小 ÷（线程数 × 4），限制在 1~16MB；取消勾选则使用设置页的手动分块大小（1~64MB）。
2. **分块级重试与慢块拆分**：单个分块失败自动重试（从该块已写入字节继续，不从头开始），重试仍失败则任务暂停，可点“继续”重试；过慢的分块会自动拆分并交给空闲线程，不再拖慢整体进度。
3. **断点续传升级**：正常下载、暂停、意外中断都会保存断点（`.part`/`.meta`，含文件大小与校验信息），下次下载同一链接自动续传；点“取消”则删除未完成文件、放弃断点。设置页可查看断点缓存占用大小并一键清理。
4. **响应性修复**：暂停/取消即时生效、界面不再卡顿；服务器无响应时点取消最坏 8 秒内停止（此前可能一直等到下载超时）；进度信息（速度/剩余时间）显示完整。
5. **批量下载修复**：“暂停全部”→“继续全部”后任务先显示“排队中”，拿到下载名额后才变为“下载中”，严格不超过并行上限；失败任务可在列表中单独重试。

**镜像源**

6. **镜像模板**：设置页可添加多条镜像，用 `{url}` 作为原链接占位符（如 `https://ghfast.top/{url}`）；内容不可用或与直连不一致的镜像自动跳过。
7. **三种策略**：仅直连（不使用镜像）／镜像优先（点下载立即从直连开始，下载中后台测速全部镜像，完成后自动切换最快镜像）／直连优先（过慢时按列表顺序自动切换镜像）。镜像测速并发可调（默认 3）；直连失败也会自动尝试镜像。
8. **一键复制链接**：搜索页与抓取页底部新增链接列表——双击复制单条、“复制全部”一键复制；主文本框仍可自由选中批量复制，互不影响。
9. **命令行新增参数**：`--chunk-size`（手动分块大小，MB）、`--discard`（放弃指定链接的断点）、`--mirror`（镜像模板，可多次指定）、`--mirror-strategy`（direct / mirror_first / auto_fallback）、`--mirror-speed-limit`（低速切换阈值，KB/s）。

### v1.2.1 · 链接解析与验证码

（本版为 1.2.0 的小版本升级，以下均为相对 1.2.0 的新增与修复。）

**新增：链接解析**

1. **直链优先、零额外流量**：直链直接下载，不经过解析；只有下载目标返回网页（假直链）或被站点拒绝（403/429）时才自动解析。
2. **跳转链跟随**：自动跟随 HTTP 302、`<meta>` 刷新与 JS 跳转（含 `var x = 条件 ? "A" : "B"` 这类按 true/false 取值的内联脚本）。
3. **下载选项列表**：从 JSON-LD / og:image / srcset / 视频音频标签 / 下载按钮 / 内联 JS 变量中提取候选并按可信度排序；多候选时弹出选择窗口（下载选中 / 全部下载 / 复制选中链接 / 取消，双击即下载）；设置可改为“自动选择最佳”。
4. **多清晰度枚举**：图片候选自动枚举尺寸 token（`_340`~`_4096`、`w=` 参数、`@2x`、无后缀原图），HEAD 并发验证后只列出真实存在的档位。
5. **参数嵌套直链提取（通用）**：自动解码 `?url=`、`?image-url=`、`?target=`、`?redirect=` 等参数里嵌套的真实下载地址（URL 编码、协议相对地址均可）；页面路径含 `-<数字id>` 时按上下文优选主内容直链；相关推荐内容严格过滤。
6. **人机验证**：识别验证码表单并拉取图片（PNG/GIF 内嵌显示），输入后带会话 Cookie 自动提交、可多次重试；主窗口“取消下载”会同步关闭验证窗口。
7. **拦截提示**：解析对瞬时网络错误自动重试 1 次；被风控拒绝（403/429）立即提示并给出“用浏览器手动获取直链”的指引；严格 Cloudflare 站点明确提示“停止使用本工具下载、改在浏览器中获取直链”。
8. **防盗链支持**：下载解析出的直链时自动携带页面 Referer；解析出的直链绑定浏览器会话或已失效被拒时，明确提示改用浏览器复制下载链接。
9. **命令行新参数**：`--resolve` / `--list-options`（列出选项不下载）、`--pick best|N|URL`（多选项选择）、`--no-resolve`（关闭自动解析）；CLI 验证码保存图片并提示输入。
10. **站点扩展点**：`anysearch_link_resolver.py` 内置 `SITE_RULES` 注册表——网站改版/新增接口时注册一条（主机名正则 + 解析函数）即可，GUI / CLI / 下载引擎无需改动；《使用说明》“五、链接解析 → 自定义站点规则”附完整可复制示例。

**改进：下载与修复（相对 1.2.0）**

11. **断点续传增强**：暂停后“继续下载”复用上次解析出的直链（签名直链每次解析都不同，重新解析会丢断点；直链失效时自动重新解析）；≤1MB 但支持 Range 的小文件（如 .torrent、README.md）同样支持断点续传。
12. **请求头与风控**：解析请求改用完整浏览器请求头（显著降低被 Cloudflare 等风控拦截的概率）。
13. **修复 1.2.0 既有问题**：单任务暂停/取消按任务隔离关闭连接（批量窗口任务互不误伤）；206 响应 Content-Range 无总大小时不再误用分片长度；修复大小校验“先删后读”导致错误信息被掩盖；镜像切换标记每源重置（防连环切换）；镜像测速/切换共享状态加锁；修复批量重建任务残留进度条目导致界面卡死；清空搜索/抓取结果同步清空保存缓存；设置文件权限收紧（0600）；关窗时优雅停止下载（等待断点落盘）；CLI/API 网络错误不再打印 traceback；下载入口仅接受 http/https；修复“暂停后点取消”无活动任务导致界面停在“取消中”无法恢复（暂停态取消立即删除断点并恢复界面，单任务与批量行均适用）。

> 说明：经实测 AnySearch API 的 extract 工具无法用于抓取直链（正文提取会丢弃下载链接、图站直接失败），故本功能为本地解析实现，不消耗 API 配额。
